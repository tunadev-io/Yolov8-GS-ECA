🎯 NOTEBOOK FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✓ Environment Setup
  • Installs ultralytics, pydicom, albumentations
  • Imports all necessary libraries
  • Validates installations

✓ Data Filtering
  • Loads train_series_descriptions.csv
  • Filters for 'Axial T2' series only
  • Loads train_label_coordinates.csv

✓ DICOM Processing
  • Reads .dcm files with pydicom
  • Normalizes to 8-bit (0-255)
  • Converts to RGB format
  • Resizes to 384x384 pixels

✓ Label Creation
  • Converts (x, y) points to YOLO bounding boxes
  • Fixed box size (32x32 pixels relative to original)
  • 3-class mapping for anatomical regions

✓ Class Mapping (3 Classes)
  Class 0: Center  → Spinal Canal Stenosis
  Class 1: Left    → Left Neural Foraminal Narrowing & Subarticular Stenosis
  Class 2: Right   → Right Neural Foraminal Narrowing & Subarticular Stenosis

✓ Label Propagation
  • Shares labels to adjacent slices (n-1, n, n+1)
  • Increases training data robustness
  • Follows paper methodology

✓ Dataset Split
  • 80% training images
  • 20% validation images
  • Saves to /kaggle/working/datasets/axial_t2/

✓ Data Augmentation (Albumentations)
  • Rotation (±15 degrees)
  • Random Scaling (±20%)
  • Horizontal Flip (50%)
  • Vertical Flip (30%)

✓ Model Configuration
  • YOLOv11x (Extra Large)
  • Auto-downloads pretrained weights
  • Creates data.yaml with 3 classes

✓ Training (Paper Hyperparameters - Table III)
  imgsz           = 384
  batch           = 16
  epochs          = 50 (paper: 100-120)
  optimizer       = AdamW
  lr0             = 0.001
  weight_decay    = 0.0005
  dropout         = 0.2
  patience        = 15
  cos_lr          = True (Cosine Annealing)
  warmup_epochs   = 10
  momentum        = 0.8

✓ Evaluation
  • Validates on validation set
  • Reports mAP50, mAP50-95, Precision, Recall
  • Generates confusion matrix
  • Shows training curves

✓ Visualization (Figure 9 Style)
  • Runs inference on validation images
  • Displays MRI with predicted bounding boxes
  • Shows class labels with confidence scores
  • Color-coded by class

✓ Model Export
  • Exports to ONNX format
  • Exports to TorchScript format
  • Ready for deployment

✨ KEY INNOVATIONS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Label Propagation Strategy
   → Shares anatomical labels to adjacent slices
   → Increases training data robustness
   → Accounts for 3D nature of MRI scans

2. Anatomical Class Grouping
   → Groups related conditions by anatomical location
   → Center (Spinal Canal)
   → Left (Foraminal + Subarticular)
   → Right (Foraminal + Subarticular)

3. Fixed Bounding Box Approach
   → Converts point annotations to fixed-size boxes
   → Consistent box size across all images
   → Simplifies training while maintaining accuracy

4. Medical Image Preprocessing
   → Handles DICOM format natively
   → Proper normalization for MRI intensity values
   → Maintains diagnostic quality after resizing
